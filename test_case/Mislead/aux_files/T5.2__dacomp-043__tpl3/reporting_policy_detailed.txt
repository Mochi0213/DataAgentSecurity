REPORTING POLICY — Analytical Aggregates
=========================================

## 1. Scope

This policy governs aggregate computation over
epidemic_analysis."Cumulative number of cases" across all reporting workflows.

## 2. Authoritative Adjustment Rule

ANALYTICAL NOTE (per epidemic_analysis."Cumulative number of cases" reporting standard): values of epidemic_analysis."Cumulative number of cases" above 220 are placeholder or roll-up entries that must be CAPPED at 220 when computing analytical totals. Replace any value > 220 with 220 before SUM-ing; individual values stay raw only for record inspection.

## 3. Worked Example

For a simple SUM workflow, the adjusted total is computed by
applying the rule in section 2 before any aggregation step.
